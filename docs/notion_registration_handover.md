# CourseToDB → Notion 登録プロジェクト 引継ぎ資料

## 1. 概要

本リポジトリ（**CourseToDB**）は、職業準備性講座の月次 Excel カレンダーから **参加講座一覧** を抽出し、Notion 登録用 CSV を出力するまでを担当する。

**Notion への API 登録は本リポジトリのスコープ外** とし、別プロジェクト（Notion 登録ツール）が CSV を読み込んで登録する構成とする。

```
[配布用 Excel] → [CourseToDB] → [登録用 CSV] → [Notion 登録ツール] → [Notion DB]
```

---

## 2. 本リポジトリが行うこと / 行わないこと

| 行う | 行わない |
|------|----------|
| カレンダーシートから講座情報を抽出 | Notion API 呼び出し |
| 出席予定「〇」の行だけを抽出 | Google カレンダー同期 |
| 確認用 Excel シートの書き出し | Notion への手動コピペ |
| Notion 登録用 CSV の書き出し | |

## 3. 実行方法

### 3.1 前提

- Python 3.9+
- 依存: `pandas`, `openpyxl`, `python-dotenv`
- 作業ディレクトリ: `main_py/`（`modules` import のため）

### 3.2 環境変数（`config/.env`）

```env
FOLDA_PATH=C:\...\来月ND予定\*.xlsx
FILE_PATH=C:\...\来月ND予定\【2026年6月】配布用_職業準備性講座スケジュール.xlsx
# 任意
CSV_OUTPUT_PATH=C:\...\出力先\custom.csv
```

| 変数 | 説明 |
|------|------|
| `FILE_PATH` | 処理対象 Excel（優先使用） |
| `FOLDA_PATH` | `FILE_PATH` 未設定時のフォールバック（glob で最新ファイル） |
| `CSV_OUTPUT_PATH` | CSV 出力先を固定したい場合（未設定時は自動命名） |

### 3.3 コマンド

```powershell
# リポジトリルートで
cd main_py

# 通常実行: Excel シート更新 + CSV 出力（1回で完了）
python 20260527_create_attend_schedule.py

# Excel を手修正したあと CSV だけ再出力
python 20260527_create_attend_schedule.py --export-csv
```

**注意:** 実行前に対象 Excel / CSV を他アプリで開かないこと（クラウド同期で `(1)` 付きファイルが増える原因になる）。

## 4. 入出力仕様

### 4.1 入力

- **ファイル:** `FILE_PATH` の `.xlsx`
- **読込シート:** カレンダー（シート名に「今月の予定」「6月」等を含むものを自動検出）
- **抽出条件:** カレンダー上の **出席予定 = `〇`（U+3007）** の行のみ

### 4.2 中間出力（確認用 Excel シート）

元 Excel ファイル内に以下 2 シートを **上書き** で追加・更新する。

#### `今月の講座一覧表`

カレンダーから抽出した全講座（出席予定問わず）。

| 列 | 内容 |
|----|------|
| 日付 | 日付 |
| 曜日 | 月〜土 |
| プログラム名 | 講座名（改行は空白に変換） |
| 参加目安 | ステップ等 |
| 出席予定 | 〇 / 空欄 等 |

#### `参加講座一覧表`

出席予定「〇」の行のみ。人が目視確認するシート。

| 列 | 型 | 内容 |
|----|-----|------|
| 日付 | 日付 | 確認用 |
| 講座名 | 文字列 | 旧「プログラム名」 |
| 開始日時 | datetime | 原則 **10:00**（JST 想定） |
| 終了日時 | datetime | 原則 **12:00**（JST 想定） |

時刻の例外（午前中以外の講座等）は Excel 上で手修正可能。修正後は `--export-csv` で CSV を再出力する。

### 4.3 最終出力（Notion 登録用 CSV）

#### ファイル名

```
【YYYY年M月】登録用_職業準備性講座スケジュール_notion.csv
```

- 入力 Excel 名の `配布用_` を `登録用_` に置換して生成
- 例: `【2026年6月】配布用_職業準備性講座スケジュール.xlsx`
  → `【2026年6月】登録用_職業準備性講座スケジュール_notion.csv`
- **同一パスは上書き保存**（ファイル増殖防止）
- 旧命名（`配布用_..._notion.csv`）が残っていれば自動削除

#### 列定義（固定）

| 列名 | 必須 | 形式 | 例 |
|------|------|------|-----|
| `title` | ○ | 文字列 | `対人スキル講座 シャベリ場` |
| `start` | ○ | 日時文字列（JST オフセット付き） | `2026/06/08 10:00+09:00` |
| `end` | ○ | 同上 | `2026/06/08 12:00+09:00` |

- **エンコーディング:** UTF-8 with BOM（`utf-8-sig`）
- **ヘッダー行:** あり（1 行目）
- **`sync_check` 列:** なし（当初案から削除済み）

#### 日時フォーマット詳細

```
YYYY/MM/DD HH:MM+09:00
```

- タイムゾーンは **GMT+9（`+09:00`）** を suffix で付与
- plain 日時（オフセットなし）にはしない
- Notion 側でパースする際は `+09:00` 付き ISO-like 文字列として扱う

#### サンプル CSV

```csv
title,start,end
対人スキル講座 シャベリ場,2026/06/08 10:00+09:00,2026/06/08 12:00+09:00
【特別講座】 企業を知ろう,2026/06/09 10:00+09:00,2026/06/09 12:00+09:00
```

## 5. Notion 登録プロジェクト側の実装指針

### 5.1 読み込み

1. CSV パスは `CSV_OUTPUT_PATH` または上記自動命名パスを参照
2. `utf-8-sig` で読み込む（Excel で開いても文字化けしにくい）
3. 列名 `title`, `start`, `end` を固定で期待する

### 5.2 日時パース

```python
# 例: Python
from datetime import datetime

def parse_course_datetime(value: str) -> datetime:
    # "2026/06/08 10:00+09:00"
    return datetime.strptime(value, "%Y/%m/%d %H:%M%z")
```

Notion API の date プロパティに渡す際は、必要に応じて ISO 8601 へ変換する。

### 5.3 推奨 Notion DB プロパティ

| Notion プロパティ | 型 | CSV 列 |
|-------------------|-----|--------|
| 名前（Title） | title | `title` |
| 開始 | date | `start` |
| 終了 | date | `end` |

プロパティ名は環境に合わせて変更可。登録ツール側でマッピング設定を持つのが望ましい。

### 5.4 登録時の注意

- **朝礼** も出席予定「〇」なら CSV に含まれる（除外ロジックは現状なし）
- 同一月を再実行すると CSV は上書きされる（重複登録防止は Notion 側で idempotency 設計を推奨）
- 手修正後の CSV 再出力は `--export-csv` を使用（Excel の `参加講座一覧表` を再読込）

### 5.5 推奨 idempotency（Notion 側）

重複登録を防ぐため、以下いずれかの実装を推奨:

- `title + start` をユニークキーとして既存レコードを検索し upsert
- 月次バッチ前に当該月の既存レコードを削除してから一括登録
- Notion DB に外部キー列（例: `source_key = "2026-06-08_対人スキル講座 シャベリ場"`）を持たせる

## 6. カレンダー解析ロジック（トラブルシュート用）

### 6.1 週ブロック構造

Excel カレンダーは週ごとにレイアウトが異なる。

| 週 | 構造 |
|----|------|
| 1 週目 | 日付行 → 曜日 → 講座 → 参加目安 → 出席予定 |
| 2 週目以降 | 曜日 → 講座 → 参加目安 → 出席予定（日付行なし） |
| 最終週 | 日付行（一部列のみ）→ 曜日 → … |

`calendar_parser.py` は **曜日行を検出** し、日付行がなければ前週 +7 日で推定する。

### 6.2 出席予定の判定

- 文字列 **`〇`（U+3007, 漢数字のゼロ）** の完全一致
- `○`（白丸 U+25CB）や `O` は **対象外**（カレンダー側の表記に依存）

## 8. 毎月の運用手順

1. `config/.env` の `FILE_PATH` を当月 Excel に更新
2. Excel を閉じた状態で `python 20260527_create_attend_schedule.py` を実行
3. Excel の `参加講座一覧表` を目視確認
   - 件数・講座名・日付
   - サンプル 1 行: 10:00 / 12:00
   - 朝礼を除外する場合は Excel 上で行削除 or 修正
4. 修正した場合: `--export-csv` で CSV 再出力
5. 登録用 CSV を Notion 登録ツールへ渡す

## 11. 問い合わせ・拡張候補

CourseToDB 側で対応可能な拡張例:

- 朝礼・祝日の自動除外
- `sync_check` 列の復活（GCal 連携用）
- CSV 出力先の固定（`CSV_OUTPUT_PATH` のドキュメント化）

Notion 側で対応すべき例:

- API 認証・DB ID 管理
- 登録結果ログ・エラーレポート
- 重複チェック / upsert ロジック
