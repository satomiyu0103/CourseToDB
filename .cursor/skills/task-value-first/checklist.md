# task-value-first チェックリスト

着手前・完了時にコピーして使う。手順の正本は [SKILL.md](SKILL.md)。

## 着手前（A-0・A-1）

- [ ] AC / FR を読み、タスク不要の根拠があるか検討した
- [ ] 見送る場合は design-decision-record で記録し、実装を止めた
- [ ] やる場合、価値の 90% を生む 10% を 1 文で書いた
- [ ] 構造変更（難しい変更）と振る舞い変更（易しい変更）に分けた
- [ ] コミット列を先に列挙した（各コミットが単独でレビュー可能か）
- [ ] 差分が 300 行超えそうなら、さらに分割案を検討した
- [ ] 着手方針をチャットまたはセッションに 1 段落で共有した

## 実施中（A-2）

- [ ] 最低 2 案を比較し、採用理由を 1 行残した
- [ ] 公式タスクを遅らせるスコープ外改善をしていない
- [ ] 既存パターンを踏襲している
- [ ] 試験実装のエラー.md を確認し、同種ミスを繰り返していない

## 完了時（A-3）

- [ ] 動作確認・テストを実施した
- [ ] agent-session-record の `## 学び` を 1 段落書いた
- [ ] 昇格候補（rules / skills / 試験実装のエラー 等）があれば 1 行記載した
- [ ] 巨大な単一 diff になっていない（git_workflow §PR 粒度）
